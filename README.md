# 得到知识红包伴侣 · 网页版 0.1.4

独立的网页插件仓库，与 Android「知识红包伴侣」仓库分开维护；不引用、构建或修改 Android 源码。

在得到网页右上角增加「知识红包」入口，点击展开 380px 宽的轻量面板。整理最近学习中的课程红包，显示官方到期日，点击后在官方网页阅读全文。

采用得到网页的橙色主色 `#FF6B00` 与 App 的浅橙底色 `#FFF7F2`。面板不遮罩、不锁住网页；点击外部、按 Escape 或再次点击入口即可收起。

本项目由白牙独立开发，非得到官方产品，与得到无隶属或合作关系。仅整理当前账号已有权限的内容。

[下载最新版本](https://github.com/dingaiminGIT/dedao-redpacket-web-extension/releases/latest) · [项目介绍](https://baiyalab.com/projects/dedao-redpacket-web-extension) · [反馈问题](https://github.com/dingaiminGIT/dedao-redpacket-web-extension/issues)

## 安装

这是一个标准 Manifest V3 浏览器扩展，需要浏览器支持 MAIN world 内容脚本和 `chrome.storage.session`。没有上架商店，当前通过开发者模式加载。

1. 解压发布包，找到包含 `manifest.json` 的文件夹；也可以直接选择本仓库根目录。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。使用源码安装时选择本仓库根目录。macOS 目录选择器可按 `⌘⇧G` 粘贴文件夹路径。
4. 打开或刷新 `https://www.dedao.cn/`，在 Chrome 中登录你自己的得到账号。不同浏览器的登录状态和插件缓存不会自动同步。
5. 点击右上角「知识红包」，面板会先显示缓存并按需自动刷新。工具栏的扩展按钮也可以打开得到首页和面板。

已在 Ego Lite 0.5.1.13 中实际安装并验证同步、阅读全文、短链接自动收录和刷新后的持久缓存。其他浏览器尚未实际验收。

加载后请保留此目录；Chrome 直接使用目录中的文件。下载的 ZIP 需要先解压，不能直接作为插件目录选择。可在 Chrome 工具栏的扩展菜单中固定「得到知识红包伴侣」。

更新代码后，在扩展管理页点击「重新加载」，再刷新得到网页。卸载可在扩展管理页移除此扩展。

## 使用

- **自动刷新**：打开面板时默认检查更新；距上次完整成功刷新不足 5 分钟时直接使用缓存。失败或停止后的同一页面自动重试至少间隔 1 分钟。链接收录使用自己的核验流程，不触发一次完整扫描。
- **刷新红包**：可随时手动刷新，不受上述 5 分钟间隔限制。读取最多 5 页、100 条最近学习记录；发现候选后重新核验红包权益。已有缓存和手动收录的条目也会重新核验。
- **继续查找**：接着读取更早的 5 页记录。可重复点击，直至官方接口返回没有更多记录。刷新或重新加载网页后从头开始查找。
- **搜索与筛选**：直接搜索文章/课程；点击「筛选」展开课程、权益状态与排序选项。筛选与添加链接面板互斥展开，以保留列表空间。
- **添加链接**：点击顶部「添加链接」展开输入框，再粘贴 `https://d.dedao.cn/...` 短链接、官方课程文章链接或 `/share/trialReading` 分享链接。在新标签打开官方页面后自动尝试收录；若未登录或没有红包权益，会提示原因。此操作不会替你点击领取或购买。
- **收录当前文章**：只在红包文章或分享页显示此按钮。
- **阅读**：再次核验权限后打开官方 PC 阅读页。正文和播放仍由得到处理。
- **停止**：停止后续同步请求，保留已核验结果；新发现但未核验的条目标为「待核验」。
- **清除本账号缓存**：先显示确认说明，确认后仅清除扩展的本地列表，不会删除得到账号里的文章、红包或学习记录。

搜索无结果时可点击「重置筛选」恢复；24 小时内到期的红包会突出提示。

缓存不等于实时权限；面板标注上次核验时间，实际阅读前会重新检查。切换账号后重新打开面板或刷新网页，不同账号使用各自的缓存。

## 当前范围

**这是「最近学习中的红包」，不是完整红包收件箱。** 未读红包、同一课程中的其他红包文章可能不会出现在最近学习记录里，可以用分享链接补充。

第一版仅收录课程文章（资源类型 65），不支持听书或电子书红包。不提供音频下载、离线正文、自动领取、购买或连续播放。

官方接口可能调整。接口失败时展示错误/待核验状态，不伪造到期日或放行失效权益。数据量上限为每个账号 500 条本地记录。

## 权限与数据

- 仅声明 `storage` 权限，内容脚本只运行在 `https://www.dedao.cn/*`。
- 不申请 Cookie、浏览历史、下载或全站访问权限。
- 使用得到当前网页会话请求固定的官方只读接口；CSRF 参数只留在页面请求中。
- 本地仅存账号分组标识、文章标识、标题、课程、官方到期文案、截止时间、核验状态和时间，以及是否手动收录。
- 不保存或传送登录凭据、正文、音频地址；没有自建服务器或统计服务。

## 开发与验证

没有 npm 依赖。修改 `core.js` 或 `bridge.js` 后，先生成主世界脚本，再重新加载扩展和得到页面。仓库与安装包已包含生成文件，可直接加载。

```sh
python3 scripts/build-web-extension.py
node --test tests/web-extension/*.test.cjs
python3 scripts/package-web-extension.py
```

测试需要从仓库根目录执行。刷新按钮采用得到网页一致的橙底白字。

代码分层：`core.js` 处理字段、链接、筛选和分页；`bridge.js` 在页面主世界调用官方接口，只返回白名单元数据；`content.js` 在隔离世界绘制面板和管理缓存；`background.js` 处理扩展按钮和链接导入标签。

`bridge-main.js` 由 `core.js` 和 `bridge.js` 生成，避免相同脚本路径跨执行世界加载时出现初始化缺失。打包命令会自动重新生成。

验证范围见 [验证说明](docs/VALIDATION.md)，数据处理方式见 [隐私政策](PRIVACY.md)。
