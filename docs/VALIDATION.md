# 验证范围

版本 0.2.7，2026-10-02。

- 33 项 Node 测试通过，覆盖官方权益字段、失效判定、缓存、分页、账号隔离、并发、学习状态及位置边界。
- 真实扩展内已移除权益状态控件，列表始终使用有效红包过滤，课程选项来自有效红包。当前账号勾选隐藏已学完显示 13 篇，重置后显示 17 篇，两种情况下均未显示失效文章。
- 课程匹配、排序选项点击、键盘方向键切换、重置默认排序已验证。课程独占一行，排序在下一行。390×844 与 320×500 视口下无横向溢出。
- 权益来自官方 `authority_intro.red_packet_rights`，与 App 判断一致。已失效条目不请求文章详情；详情接口明确无红包权益时更新状态，其他网络或业务错误不会被当作失效。
- 官方文章搜索取得网页编号后严格核对数字 ID，不按标题相似度放行。仅传递白名单元数据，不缓存正文、音频或登录凭据。
- 每批最多读取 100 条领取记录，可继续加载历史。列表按账号缓存，仅支持课程文章。
- 学习完成状态对应官方 `is_finished` / `progress` / `listen_finished`，不把仅打开网页视为学完。

此前已在同一真实扩展环境验证官方网页阅读、分页、缓存持久化、拖动及位置记忆。本版重点验收有效红包过滤与筛选布局。浏览器操作使用 ego-browser，未自动操作 Chrome；截图接口在本环境持续超时，未声称完成像素级截图验收。Chrome 用户更新后需重新加载扩展并刷新得到网页。
