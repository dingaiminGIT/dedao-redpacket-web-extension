# 验证范围

版本 0.2.3，2026-10-01。

- 27 项 Node 测试通过，包括已领取列表解析、未学习条目、数字编号严格匹配、同名搜索结果排除、账号变更、固定跨域地址、异常响应、缓存去重和自动刷新时限。
- 通过官方当前 H5 脚本的 `fetchRedPacketProducts` 定位 `/native/api/redPacket/products`，其原生分支对应 App 使用的 `/mustard-view/v1/red_packet/category/list`。
- 实测需要当前账号数字 `uid`；仅扫码登录而未传该字段仍为空。数字 ID 从当前 PC 会话的 `/api/hades/v1/group/has` 取得，不从用户输入、配置或其他账号取得。
- 已安装扩展在 Ego Lite 中刷新 100 条领取记录，核验得到 21 篇有效课程红包；第二页可继续读取，刷新网页后缓存和分页入口仍保留。
- 插件点击阅读后实际打开官方 PC 文章页，标题和正文正常呈现；阅读前再次核验当前账号红包权限。
- 文章映射使用官方搜索返回的网页编号，随后严格比较文章接口返回的数字 ID。映射失败保留为待核验，不用标题相似度放行。
- 空缓存实测第一篇约 1.8 秒出现，100 条领取记录 / 21 篇有效红包约 6.8 秒完成；最大同时核验 4 篇，首篇可在同步结束前阅读。单次测量不代表所有网络条件。
- 实测 21 篇中 11 篇显示已学完；学习筛选刷新页面后仍保留。完成判定与 App 的 is_finished / progress 规则对应，并读取网页音频 listen_finished；不将 is_read 作为学完证据。
- 首批读取上限 100 条，可以继续加载历史；不声称一次刷新覆盖全部历史。仅支持课程文章，不含听书、电子书或 Android 同步。
- 本次实际验证列表、分页、缓存和阅读，未全面验收所有浏览器和所有功能。

本次浏览器操作统一通过 ego-browser，未自动控制用户 Chrome。Chrome 使用同一插件目录时，需要在其扩展管理页手动重新加载，并刷新得到网页。

- 常驻筛选在 1440×900、390×844、390×500 视口下通过 DOM 尺寸与交互检查，无横向溢出；学习状态切换及重置正常。截图接口超时，本轮未据此声称完成像素级视觉验收。
