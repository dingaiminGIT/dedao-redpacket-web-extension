# 验证范围

版本 0.2.4，2026-10-02。

- 31 项 Node 测试通过，覆盖领取列表权益布尔字段、失效状态迁移、重新领取后的缓存截止时间、文章接口明确拒绝权限、异常响应、数字编号匹配、账号隔离、分页、并发和学习状态筛选。
- 权益依据官方已领取列表的 `authority_intro.red_packet_rights`，与 App 的判定一致。`false` 归入失效，不再请求文章详情；`true` 显示有效并补全网页信息。
- 在当前登录账号实际复现 5 篇持续报错：已领取接口均返回无红包权益，文章接口均返回业务码 4000、无阅读全文权限及 `is_red_packet_try: false`。修复后 5 篇均正确显示失效。
- Ego Lite 真实扩展环境连续刷新两次，均显示 17 篇有效红包，无“待重试”提示。首批 100 条记录中收录 98 篇课程文章，其中 81 篇失效；两次刷新合计仅发出 34 次文章详情请求。失效筛选内没有阅读按钮。以上数字仅为本次账号实测，不代表其他账号或全部历史。
- 仅接受文章接口明确携带无红包权益及文章编号的 4000 响应，并继续严格核对数字编号；其他业务错误、网络失败和缺失权益字段仍报错，不推断为失效。
- 文章映射使用官方搜索返回的网页编号，随后严格比较数字 ID。详情加载失败不覆盖已领取列表确认的权益，不用标题相似度放行阅读。
- 已验证固定官方领取接口 `/native/api/redPacket/products`。当前账号数字 ID 从 PC 会话的 `/api/hades/v1/group/has` 取得，不接受用户输入的其他账号；列表请求不传登录 Cookie。
- 学习状态对应 App 的 `is_finished` / `progress`，并读取网页音频 `listen_finished`；不将仅打开网页视为学完。
- 每批最多读取 100 条领取记录，可继续加载历史；缓存按账号保存。仅支持课程文章，不含听书或电子书。

此前已在同一真实扩展环境验证官方网页阅读、分页、缓存持久化、学习筛选以及常驻筛选的响应式尺寸。本次重点复测权益状态和重复刷新；未全面验收所有浏览器。本次浏览器操作统一通过 ego-browser，未自动控制用户 Chrome。Chrome 使用同一插件目录时，需要在其扩展管理页重新加载，再刷新得到网页。
